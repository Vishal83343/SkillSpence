# SkillSpence
An AI-powered web application built with Python and Streamlit for automated resume skill-gap analysis, smart expense tracking, financial insights, and PDF reports.
# 💼 TalentFin AI — AI Resume Analyzer & Smart Expense Tracker

An intelligent all-in-one productivity suite built with **Python** and **Streamlit** that bridges career development with personal finance management. 

---

## 🌟 Key Features

### 📄 1. AI Resume Analyzer
- **Automated Skill Detection**: Extracts technical and soft skills from uploaded resumes (PDF/DOCX).
- **Skill-Gap Analysis**: Compares candidate skills against job profiles and highlights missing skills.
- **Career Recommendations**: Suggests targeted learning paths to improve profile match scores.

### 💰 2. Smart Expense Tracker
- **Intelligent Categorization**: Automatically categorizes transactions (Food, Travel, Bills, Shopping, etc.).
- **Interactive Financial Visualizations**: Generates weekly and monthly spending charts using **Pandas** & **Matplotlib**.
- **Savings Advice & PDF Export**: Produces downloadable financial summaries with automated saving tips via **ReportLab**.
- **Voice Feedback**: Integrated offline Text-to-Speech (TTS) alerts powered by **pyttsx3**.

---

## 🛠️ Tech Stack

- **Language:** Python 3.10+
- **Frontend / Framework:** Streamlit
- **Data Analytics & Charts:** Pandas, Matplotlib, Seaborn
- **Text & PDF Processing:** Regular Expressions (Regex), NLP, ReportLab, PyPDF2
- **Audio / Voice:** pyttsx3
